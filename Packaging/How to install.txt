AIRLOOM - the portable copy
===========================

This folder runs without installing anything: Airloom.exe works on its own on
Windows 10 or 11 (64-bit). If you'd rather have a Start menu entry, a desktop
shortcut and sets that open with a double-click, use Airloom-Setup instead.

1. Put the "Airloom" folder somewhere to keep it, e.g. Documents.

2. Double-click Airloom.exe. If Windows shows "Windows protected your PC",
   click "More info" then "Run anyway" (until Airloom's builds are signed).
   For a shortcut: right-click Airloom.exe > "Show more options" > "Send to" >
   "Desktop (create shortcut)".

3. Set it up once on each computer:
   - Plug in your audio interface (install its driver first) and pick it in
     Settings > Audio. Use the smallest buffer that plays without crackles.
   - MIDI controllers (an Akai MidiMix, a Fire, a keyboard) are found
     automatically.
   - Install any plug-ins your sets use from their makers, then use
     GROUP > Instrument group > Scan for plug-ins once.

4. Bring sets from another computer: there, use Set > Export set as one file;
   here, Set > Open set and pick the .airloompack. It unpacks into
   Music\Airloom Sets and opens ready to play, with "Plug-ins needed.txt"
   listing anything to install.

Settings for this computer (audio device, MIDI, the last session) are kept in
%APPDATA%\Airloom; loops recorded before a set is saved are in
%APPDATA%\Airloom\Recordings.

To update, replace Airloom.exe with the new one - settings and sets carry over.
